# Identity scenario

Users, groups, a permission over one repository, a repository-scoped token and a signing
key pair, managed with the `jfrog/artifactory` and `jfrog/platform` providers. The
`terraform` CI job applies it against a running artifactweave, requires an empty plan and
destroys it; `test/terraform/run.sh` supplies the variables, including a fresh RSA key pair
for each run. See [Managing artifactweave with Terraform](../../README.md) for the
providers and authentication.
