# Repositories scenario

A local generic repository (`artifactory_local_generic_repository`) and properties on a file
deployed into it (`artifactory_item_properties`), managed with the `jfrog/artifactory`
provider. The provider cannot deploy files, so this takes two applies: the first with
`with_properties = false`, then a PUT of `fixture.txt` into `tf-generic-local`, then the full
apply. `test/terraform/run.sh` does this in the `terraform` CI job, then requires an empty plan
and destroys it. See [Managing artifactweave with Terraform](../../README.md) for the providers
and authentication.
