# Scenario README template

Every scenario under `deploy/platform/terraform/<cloud>/<scenario>` has a `README.md` with
exactly the H2 sections below, in this order (decision
[0030](../../docs/research/decisions/0030-reference-deployments.md), rule S9). The README is
the documentation a consumer reads and the description of what the scenario's acceptance
test proves, so it is written once, for a consumer. Copy everything from the first heading
down and replace each `<…>` with the scenario's text; the line under each heading says what
belongs there. `deploy/ci/lint-contract.sh` checks the headings, the markers and the lists
named below.
