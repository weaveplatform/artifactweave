# modules/gcp/storage

One private Cloud Storage bucket, with object rights on it for the service accounts in
`principals`. [`gcp/single-bucket`](../../../gcp/single-bucket/README.md) calls it once,
[`gcp/multi-region`](../../../gcp/multi-region/README.md) once per location,
[`gcp/geo-replicated`](../../../gcp/geo-replicated/README.md) once in a dual or multi-region
location, with `data_locations` and `rpo` choosing its regions and replication,
[`gcp/cdn`](../../../gcp/cdn/README.md) once, behind [`modules/gcp/cdn`](../cdn/README.md), which
grants Cloud CDN's fill account read access itself, and
[`multicloud/mirror`](../../../multicloud/mirror/README.md) once, for its GCP mirror member.
The module holds no provider block, so the caller's `google` provider and project apply
(decision [0030](../../../../../../docs/research/decisions/0030-reference-deployments.md)).

## What it creates

- `google_storage_bucket.blobs`: the bucket, labelled with `labels`, in `location` (and
  `data_locations`, when given), with soft delete off and the expiry backstops below;
  `force_destroy` lets a destroy empty it.
- `google_storage_bucket_iam_member.app`: `roles/storage.objectAdmin` on the bucket for each of
  `principals`.

## Invariants

- No public access: public access prevention is enforced (`tests/security.tftest.hcl`, run
  `public_access_is_prevented`).
- Access is identity-based: uniform bucket-level access, so no object ACL applies
  (`tests/security.tftest.hcl`, run `access_is_uniform`).
- The principals get object rights on this bucket only, and no bucket or project
  administration (`tests/security.tftest.hcl`, run
  `principals_get_object_rights_on_this_bucket_only`).
- Labels reach the bucket, the one resource that takes them (`tests/security.tftest.hcl`, run
  `labels_reach_the_bucket`).
- `<store_prefix>_uploads/` expires after 2 days (`tests/lifecycle.tftest.hcl`, run
  `abandoned_upload_parts_expire_after_two_days`).
- Each `expiring_prefixes` entry expires after its days (`tests/lifecycle.tftest.hcl`, run
  `expiring_prefixes_expire_after_their_days`).
- Deleted objects are not kept: soft delete is off (`tests/lifecycle.tftest.hcl`, run
  `deleted_objects_are_not_kept`).
- A location alone is one region, and `data_locations` make a dual-region at `rpo`
  (`tests/inputs.tftest.hcl`, runs `a_location_alone_is_one_region` and
  `data_locations_make_a_dual_region`).
- `store_prefix` is normalised as the backend does: no leading slash, one trailing slash
  (`tests/inputs.tftest.hcl`, runs `store_prefix_gains_a_trailing_slash` and
  `store_prefix_loses_a_leading_slash`).
- A destroy keeps a bucket that holds objects unless `force_destroy` is true
  (`tests/inputs.tftest.hcl`, run `force_destroy_is_off_by_default`).
- TLS and encryption at rest are Cloud Storage's own, with no setting to turn them off: its
  endpoints serve HTTPS and every object is encrypted with Google-managed keys. No test can
  assert them on a plan.

## Accepted findings

| ID | Resource | Why |
|---|---|---|
| GCP-0007 | `google_storage_bucket_iam_member.app` | `roles/storage.objectAdmin` is bound to this one bucket, not the project, and the backend needs all of it, deleting the temporary parts it composes included. |
| GCP-0066 | `google_storage_bucket.blobs` | Google-managed encryption keys; a customer-managed key would add a KMS key ring and its grants to manage. |
| GCP-0077 | `google_storage_bucket.blobs` | No access-log bucket: Cloud Audit Logs record the administrative calls, and object access logs need a second bucket. |
| GCP-0078 | `google_storage_bucket.blobs` | No versioning: blobs are content-addressed and never rewritten, and versioning would keep every deleted upload part, the cost the soft delete setting turns off. |

## Usage

Scenarios in this repository use the relative source, `../../modules/gcp/storage`; anyone else
can use the git source, which names the current release.

```hcl
module "storage" {
  source = "git::https://github.com/weaveplatform/artifactweave.git//deploy/platform/terraform/modules/gcp/storage?ref=v0.0.0" # x-release-please-version

  name       = "artifactweave-example"
  location   = "europe-west2"
  principals = { app = "artifactweave@example-project.iam.gserviceaccount.com" }
}
```
